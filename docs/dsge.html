Three macro models, solved as you move the sliders

Each model below is written the way Dynare's model block reads and handed to Cozy's dsge package, which finds the steady state, linearises with exact derivatives, and solves for the decision rule. Nothing is precomputed and nothing is sent to a server: the interpreter runs in this page as WebAssembly, and every slider move re-solves the model.

      How it works. The equations are compiled into a residual function. The
    steady state is found by Newton's method and the model is linearised around it, both with
    dual numbers, so the derivatives are exact. The linear system is solved by cyclic
    reduction, and the Blanchard-Kahn condition is read from the solution's own eigenvalues.
    The package is cross-checked against an independent solver (SymPy derivatives and SciPy's
    QZ decomposition) and against Gali's closed form for the New Keynesian model.
      
    
      To use it yourself: load("dsge") in the playground
    or in a native Cozy session, then help("dsge").
